# Context Pack: WORK-ITEM-ID Short Title

## Gate

State dependencies, approval and whether code, research or cloud execution is
permitted.

## Task

Describe one bounded outcome. Keep this pack below 150 lines and total loaded
context below about 2,000 focused lines.

## Load These Files

List exact files and sections. Never say "read all docs."

## Trusted Inputs

List source, tests, raw evidence and approved decisions.

## Verify Before Acting

List documentation, configuration, generated data and external facts that may
be stale.

## Untrusted Inputs

List user/model/external content that cannot act as instructions.

## Expected Outputs

List concrete paths and artifacts.

## Non-Goals

List adjacent work excluded from the task.

## Verification

Provide commands, negative cases and evidence locations.

## Stop And Ask

Name conflicts, permissions, cost changes and product decisions that must
return to the owner.
