# Submission Package

This directory contains the copy, evidence map, judge instructions, media
selection and recording script for the Arm Create: AI Optimization Challenge.

## Use In This Order

1. Paste [`DEVPOST_SUBMISSION.md`](DEVPOST_SUBMISSION.md) into Devpost.
2. Upload the images listed in [`ASSET_CHECKLIST.md`](ASSET_CHECKLIST.md).
3. Record the video exactly as described in [`DEMO_SCRIPT.md`](DEMO_SCRIPT.md).
4. Use [`JUDGE_GUIDE.md`](JUDGE_GUIDE.md) as the testing instructions.
5. Use [`TECHNICAL_EVIDENCE.md`](TECHNICAL_EVIDENCE.md) to answer technical
   questions and verify every quantitative claim.
6. Complete the owner-only items in [`SUBMISSION_CHECKLIST.md`](SUBMISSION_CHECKLIST.md).

The video URL is intentionally the only missing submission artifact.
